Explicación Profunda - Pregunta 9 del FE Mechanical

Cálculo de Media, Mediana y Varianza para un Conjunto de Datos

Pregunta Original

9. Consider a set of three values: 4, 4, and 7.

Match each of the statistical quantities with the correct value.

Statistical Quantities: Mean | Variance | Median

Solución Paso a Paso

1

Entender los datos y el objetivo

Tenemos el siguiente conjunto de datos de 3 valores:

4, 4, 7

Necesitamos calcular tres medidas estadísticas:

  • Media (Mean): El promedio de los valores
  • Mediana (Median): El valor central cuando los datos están ordenados
  • Varianza (Variance): Una medida de la dispersión de los datos

Visualización de los Datos

4
4
7

Valor 4 (2 veces)  |  Valor 7 (1 vez)

2

Calcular la Media (Mean)

La media aritmética se calcula como la suma de todos los valores dividida entre el número total de valores:

μ = Σxᵢ / N

Donde:

  • Σxᵢ = 4 + 4 + 7 = 15
  • N = 3
μ = 15 / 3 = 5

Cálculo detallado:

Suma de valores: 4 + 4 + 7 = 15

Número de valores: N = 3

Media: 15 ÷ 3 = 5

Interpretación de la Media

La media (5) representa el "centro de gravedad" del conjunto de datos. Si todos los valores fueran iguales, cada uno sería 5.

Media μ = 5
3

Calcular la Mediana (Median)

La mediana es el valor central cuando los datos están ordenados de menor a mayor. Para un número impar de observaciones, es el valor en la posición (N+1)/2.

Primero ordenamos los datos:

4, 4, 7

Para N = 3, la posición de la mediana es (3+1)/2 = 2. Es decir, el segundo valor en la lista ordenada.

Mediana = 4

Cálculo detallado:

1. Ordenar datos: 4, 4, 7

2. Número de valores: N = 3 (impar)

3. Posición de la mediana: (3+1)/2 = 2

4. Segundo valor en la lista ordenada: 4

Mediana = 4

4

Calcular la Varianza (Variance)

La varianza mide cuán dispersos están los datos respecto a la media. Para una población (que asumimos en este caso), la fórmula es:

σ² = Σ(xᵢ - μ)² / N

Donde:

  • xᵢ = cada valor individual
  • μ = media poblacional (5, como calculamos anteriormente)
  • N = número total de valores (3)

Primero calculamos las desviaciones al cuadrado:

Valor (xᵢ) xᵢ - μ (xᵢ - μ)²
4 4 - 5 = -1 (-1)² = 1
4 4 - 5 = -1 (-1)² = 1
7 7 - 5 = 2 2² = 4
SUMA TOTAL 6

Ahora calculamos la varianza:

σ² = 6 / 3 = 2
Nota sobre Varianza Poblacional vs. Muestral

Varianza poblacional (σ²): Usa N en el denominador (como en este problema).

Varianza muestral (s²): Usa (N-1) en el denominador (corrección de Bessel).

En este caso, con N=3, si fuera varianza muestral sería: s² = 6 / (3-1) = 6 / 2 = 3.

Emparejar las cantidades estadísticas con los valores correctos

Ahora que tenemos los cálculos:

  • Mediana (Median) = 4
  • Varianza (Variance) = 2

Verificación de los resultados

Propiedades interesantes de este conjunto de datos:

  • La media (5) es mayor que la mediana (4), lo que indica una ligera asimetría a la derecha (sesgo positivo).
  • La varianza (2) es relativamente pequeña, indicando que los datos no están muy dispersos.
  • La moda (valor más frecuente) también es 4, que coincide con la mediana.
Respuesta Correcta
Mean = 5, Variance = 2, Median = 4

Las cantidades estadísticas se emparejan con los valores como se muestra arriba.

Conceptos Clave Involucrados

  • Media Aritmética (Mean): Medida de tendencia central que representa el promedio de un conjunto de datos. Se calcula como la suma de todos los valores dividida entre el número total de valores.
  • Mediana (Median): Medida de tendencia central que representa el valor central cuando los datos están ordenados. Para un número impar de observaciones, es el valor en la posición (N+1)/2. Para un número par, es el promedio de los dos valores centrales.
  • Varianza (Variance): Medida de dispersión que indica cuánto se alejan los valores individuales de la media. Se calcula como el promedio de las diferencias al cuadrado entre cada valor y la media.
  • Diferencia entre Varianza Poblacional y Muestral:
    • Poblacional (σ²): Usa N en el denominador. Se usa cuando se tienen todos los datos de la población.
    • Muestral (s²): Usa (N-1) en el denominador (corrección de Bessel). Se usa cuando se tiene una muestra de una población mayor.
  • Relación entre Media, Mediana y Moda:
    • En distribuciones simétricas: Media ≈ Mediana ≈ Moda
    • En distribuciones con sesgo positivo (a la derecha): Media > Mediana > Moda
    • En distribuciones con sesgo negativo (a la izquierda): Media < Mediana < Moda

Aplicaciones en Ingeniería Mecánica

  • Control de Calidad: La media y varianza se usan para monitorear procesos de manufactura y detectar variaciones anormales.
  • Análisis de Datos Experimentales: Estas medidas estadísticas ayudan a resumir y entender datos recopilados en pruebas de laboratorio.
  • Diseño de Experimentos: La media y varianza son fundamentales para comparar diferentes condiciones experimentales.
  • Tolerancias de Fabricación: La varianza ayuda a establecer límites de aceptación para dimensiones de piezas manufacturadas.
  • Análisis de Fallas: La media y mediana pueden usarse para analizar tiempos de falla de componentes mecánicos.
  • Ergonomía y Diseño: Estas medidas estadísticas se usan para analizar medidas antropométricas en el diseño de productos.
  • Mantenimiento Predictivo: La media y varianza de vibraciones o temperaturas pueden indicar el estado de máquinas y equipos.

Métodos alternativos de cálculo

Método 1: Fórmula computacional para varianza

σ² = (Σxᵢ²)/N - μ²

Calculamos Σxᵢ²:

  • 4² = 16 (dos veces) = 32
  • 7² = 49
  • Total: 32 + 49 = 81
σ² = 81/3 - 5² = 27 - 25 = 2

Este método es menos propenso a errores de redondeo cuando se calcula manualmente.

Método 2: Uso de calculadora/software

En calculadoras científicas o Excel:

Excel: =AVERAGE(4,4,7) = 5
Excel: =MEDIAN(4,4,7) = 4
Excel: =VAR.P(4,4,7) = 2 (poblacional)
Excel: =VAR.S(4,4,7) = 3 (muestral)

Interpretación práctica del resultado

Para nuestro conjunto de datos (4, 4, 7):

  • Media (5): Si redistribuyéramos el "total" (15) equitativamente entre los 3 valores, cada uno sería 5.
  • Mediana (4): La mitad de los valores son menores o iguales a 4, y la mitad son mayores o iguales a 4.
  • Varianza (2): Los valores están relativamente cerca de la media. La desviación estándar (raíz cuadrada de la varianza) sería √2 ≈ 1.41.

Comparación con otros conjuntos de datos

Considere estos tres conjuntos de datos con media = 5:

  • Conjunto A: (5, 5, 5) - Varianza = 0 (sin dispersión)
  • Conjunto B: (4, 4, 7) - Varianza = 2 (nuestro conjunto)
  • Conjunto C: (1, 5, 9) - Varianza = 10.67 (alta dispersión)

Nuestro conjunto (4, 4, 7) tiene una dispersión moderada.
