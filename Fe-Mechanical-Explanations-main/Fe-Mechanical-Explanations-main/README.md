# Explicaciones FE Mechanical

Este repositorio contiene 100 explicaciones detalladas de preguntas típicas del examen FE Mechanical, junto con la hoja de vida de un ingeniero mecánico con formación avanzada.

## 🚀 Características

- 100 preguntas con soluciones paso a paso
- Explicaciones de conceptos clave
- Referencias al FE Reference Handbook
- Aplicaciones en ingeniería mecánica
- Diseño responsivo y amigable
- Botón de impresión/PDF en cada pregunta
